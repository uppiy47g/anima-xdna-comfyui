# 0.2.0-alpha.2: bundled experimental INT8/AIR runtime

This experimental prerelease adds a versioned Windows x64 runtime bundle and
an installer for the fixed-shape `int8-attn-l1k64-nq8pp` profile. Package
version: `0.2.0a2`.

The bundle contains the five tuned INT8 projection/QKV artifacts, two MLIR-AIR
attention ELFs, the matching wide32 GEMM layout library, four host-kernel DLLs,
and the profile launcher. The installer verifies the GitHub release asset
digest and each file's SHA-256 before copying anything. Existing files it
replaces are preserved in a timestamped backup directory.

This is not a complete ComfyUI or driver installer. Users must first have the
custom node, the validated Windows XRT/`pyxrt`/Triton-XDNA environment, an
AMD XDNA 2 NPU, and the matching BF16 model weights. The profile remains
experimental, fixed-shape, opt-in and not quality-equivalent to the standard
BF16 path. See the [installation instructions](../../README.md#installing-and-launching-the-experimental-int8-profile)
and [runtime limitations](../../README.md#important-quality-and-numerical-limits).
The bundle does not contain ComfyUI, XRT, the driver, Python packages or model
weights. Included upstream notices are in the installed
`xdna-runtime\THIRD_PARTY_NOTICES.txt`; the relevant public source licenses
are MIT for Triton-XDNA and the pinned MLIR-AIR source, and no vendor
runtime/toolchain package is redistributed. See the upstream
[Triton-XDNA license at the artifact toolchain revision](https://github.com/amd/Triton-XDNA/blob/75679dc/LICENSE)
and [MLIR-AIR license at the pinned revision](https://github.com/Xilinx/mlir-air/blob/508ca731ef0384fd3729ac1688e0b5d9a0ef5efe/LICENSE).

To package the bundle from a validated deployment, first build the host DLLs
with `examples/build_fused_host.ps1`, then run:

```powershell
.\tools\package_int8_runtime.ps1 `
  -RuntimeRoot "<COMFYUI_ROOT>\xdna-runtime" `
  -RepositoryRoot "<CUSTOM_NODE_ROOT>" `
  -NativeDllDirectory "<CUSTOM_NODE_ROOT>\anima_xdna_poc" `
  -OutputPath ".\dist\anima-xdna-int8-runtime-0.2.0-alpha.2-win-x64.zip"
```

The resulting archive prints its SHA-256 digest. Upload that exact file to the
matching GitHub prerelease asset; the installer also verifies the release
asset digest reported by GitHub before validating the per-file manifest.
