# 0.2.0-alpha.1: opt-in direct MLIR-AIR attention

**Experimental prerelease, not a numerically equivalent or quality-approved
replacement for the baseline.** Package version: `0.2.0a1`.

## Changes

- Direct MLIR-AIR tiled QK -> scale -> online softmax -> AV for fixed Anima
  self/cross shapes; only Q, K, V and final output cross the host boundary.
- Native, instance-scoped runtime integration without process-global probe
  hooks; persistent self/cross XRT runners and SHA-256-verified ELF loading.
- Explicit AIR selection, backend diagnostics and an activation warning.
  The public default remains baseline, even with an artifact directory set.
- Reproduction scripts and sanitized QK/epilogue, BF16-output, attention,
  full-model and live-deployment evidence. No weights, captured tensors,
  local images, packed caches or compiled device binaries are distributed.

## Measured results and known limitations

Turbo V1.1, 512x512, batch 1, four Euler/simple steps, CFG 1, no LoRA,
seed `700755787614899`:

| Measurement | Baseline | AIR |
|---|---:|---:|
| Isolated paired warm sampler median, three runs/mode | 27.095 s | 18.765 s |
| Dispatches over four steps | 2,128 | 1,904 |
| H2D synchronized BO sizes | 15.354 GiB | 6.604 GiB |
| D2H synchronized BO sizes | 32.758 GiB | 16.133 GiB |

The ordinary ComfyUI environment separately completed a resident request
in 28.98 seconds, including about 24.1 seconds of sampling. User-observed
generation is approximately 25 seconds. The deployed environment must not
be described as having the isolated 18.765-second median; the normal-server
checks were not a repeated paired benchmark.

**Precision is unresolved.** Final latent NRMS versus the previous path was
29.035%; decoded RGB MAE was 15.975/255. Only 3/12 sampled attention cases
passed the additional 2% CPU attention-output NRMS gate. The unchanged
block-chain CPU gates failed later steps for both baseline and AIR.
BFP16-emulated BF16 matmuls and BF16 online-softmax state do not preserve
baseline rounding. Successful generation is not equivalent image quality.

AIR supports only 16 heads, depth 128, 1024 image tokens and 512 context
tokens, unmasked batch-1 inputs. Unsupported shapes, masks, missing/corrupt
artifacts and device failures raise errors, with no silent fallback.
Four-head placement exhausted shim DMA capacity; the measured schedule
uses two heads in parallel. K/V are re-streamed internally per query group.
Synchronized BO sizes are not physical bus-traffic measurements.

## Enable or revert

Use a source checkout and the ABI-matching Windows NPU environment. Follow
the pinned-source compilation instructions in
[the AIR guide](../../anima_xdna_poc/README.md#opt-in-direct-mlir-air-attention).
Keep build artifacts outside the repository, with `self\manifest.json`
and `cross\manifest.json` in one persistent directory.
The source distribution includes the compiler/probe examples, release notes
and public evidence. The wheel contains the runtime and custom-node packages;
it does not contain precompiled device artifacts.

```powershell
$env:ANIMA_XDNA_AIR_ATTENTION_DIR = "<PERSISTENT_AIR_ARTIFACT_DIRECTORY>"
$env:ANIMA_XDNA_ATTENTION_BACKEND = "air"
# Start ComfyUI with the usual XDNA workflow.
```

Alternatively pass `-AttentionBackend air -AIRAttentionDirectory "<DIRECTORY>"`
to `examples\run_comfyui_xdna.ps1` with its normal required arguments.
The first use warns `EXPERIMENTAL AIR attention ACTIVE`; Runtime Status
reports `attention_backend: "air_experimental"`.

To revert, stop ComfyUI, set
`$env:ANIMA_XDNA_ATTENTION_BACKEND = "baseline"` and restart. The repository
launcher defaults to baseline. Changing variables outside an already-running
server does not replace its resident MODEL.

The user's existing local AIR-default deployment is intentionally separate
from the public baseline-default release and is not changed by this PR.

## Provenance

The custom AIR schedule reuses AMD's MIT-licensed AIE microkernels from
MLIR-AIR commit `508ca731ef0384fd3729ac1688e0b5d9a0ef5efe`. Source copyright
and license notices must be preserved. The isolated experiment used
MLIR-AIR `0.0.1.2026102020+508ca73.no.rtti`, MLIR-AIE
`1.4.5.dev51+ge040370` and Triton-XDNA `3.6.0.2026093004+75679dc`.

See [detailed results](../anima-xdna-reproducibility.md#direct-mlir-air-tiled-attention-experiment),
