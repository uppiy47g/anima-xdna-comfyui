# 0.2.0-alpha.3: one-shot Windows installer and 1024x1024 runtime bundle

This experimental prerelease makes the CPU + XDNA 2 installation usable from
Comfy Desktop without hand-entered environment variables. Package version:
`0.2.0a3`.

- `tools/install_windows.ps1` installs a pinned ComfyUI, 64-bit Python 3.13
  CPU PyTorch, the Triton-XDNA toolchain, this custom node and the XRT SDK
  into one directory. Comfy Desktop then only needs **Add Existing Instance**
  and `--cpu`. See the [installation instructions](../../README.md#one-shot-windows-installer).
- The custom node reads `xdna-runtime\anima-xdna.json`, written by the
  installer, before any runtime module starts. Explicitly set environment
  variables still take precedence. A local XRT SDK in
  `%LOCALAPPDATA%\AMD\xrt-*` is detected automatically.
- The INT8/AIR runtime bundle now also contains the `self4096` AIR attention
  artifact required by 1024x1024 generation. All other bundle files are
  byte-identical to alpha.2.

The installer does not download the four Triton-XDNA toolchain wheels
(`triton-xdna`, `mlir-air`, `mlir-aie-no-rtti`, `llvm-aie`). Supply the exact
validated versions listed in `tools/windows-cp313-constraints.txt` with
`-WheelDirectory`. Upstream nightly wheels rotate; the validated `mlir-air`
nightly is no longer published upstream. The installer also does not download
models, and the INT8 profile remains experimental, fixed-shape, opt-in and not
quality-equivalent to the standard BF16 path. See the
[runtime limitations](../../README.md#important-quality-and-numerical-limits).

A new installation built by the installer produced latents and images
identical to the Comfy Desktop validation for 512x512 and 1024x1024 with
Anima Turbo V1.1 and Load Anima XDNA (Cache-backed), starting from the
configuration file alone. On that day its resident 1024x1024 prompts took
about 59 s instead of the earlier 26 s; the same installation with the
explicit Desktop environment variables was equally slow, and the cause was
not identified. See the
[installer validation record](../anima-xdna-reproducibility.md#one-shot-windows-installer-validation-2026-11-23).

The bundle does not contain ComfyUI, XRT, the driver, Python packages or model
weights. Licensing of the included artifacts is unchanged from
[0.2.0-alpha.2](0.2.0-alpha.2.md). Package the bundle as described there,
using the alpha.3 file name:

```powershell
.\tools\package_int8_runtime.ps1 `
  -RuntimeRoot "<COMFYUI_ROOT>\xdna-runtime" `
  -RepositoryRoot "<CUSTOM_NODE_ROOT>" `
  -NativeDllDirectory "<CUSTOM_NODE_ROOT>\anima_xdna_poc" `
  -OutputPath ".\dist\anima-xdna-int8-runtime-0.2.0-alpha.3-win-x64.zip"
```
